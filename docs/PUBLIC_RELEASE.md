# 公开发布检查

运行 `python3 -B scripts/check_public_release.py --history`，检查工作区、索引和本地可达历史；此命令不联网、不发布。另需人工审核身份信息、配置、测试数据和文档。无自动命中不代表无隐私风险。

public-assets.json 当前为空，不包含获批图片。新增素材须使用虚构身份、人工审核，并记录准确 SHA-256；旧历史中的不同字节也需独立审核。不得通过添加散列绕过审核。

禁止纳入运行数据库、导出、日志、认证 profile、Cookie、token、备份和真实学生数据。学校配置使用私有部署文件；.env.example 只保存占位值。每次发布应执行后端和插件测试，并审核完整候选文件清单。
