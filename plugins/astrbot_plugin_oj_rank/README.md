# OJ 榜单查询

这是一个只读 AstrBot 插件。它只读取容器内 `/oj-rank-share` 的总榜、两院榜 JSON 与图片，不会访问 WebVPN 登录态、浏览器配置或 SQLite 数据库，也不会主动向群聊推送消息。

普通命令：

- `/榜单`：发送第 1 页天梯总榜图片，每页 20 人。
- `/榜单 2`：发送第 2 页（第 21–40 名）。
- `/计院榜单 [页码]`、`/软院榜单 [页码]`：按配置指定快照 固定划分的两院图片榜；各自从第 1 名连续排名。
- `/班级榜单 学号前10位`：按学号前 10 位筛选，例如 `/班级榜单 2026100101`；每个班级固定为一张图片，超过 60 人时也保留完整名单。
- `/专业榜单 学号前8位 [页码]`：按学号前 8 位筛选，例如 `/专业榜单 20261001`；每页 20 人，可用 `/翻页` 继续查看。
- `/翻页 2`：发送指定页；不带页码时接着该用户上次查看的下一页。
- `/最卷班级`、`/最卷专业`：按 AC 总量排序的班级与专业统计图片。
- `/查榜 学号或昵称`：按完整学号优先、昵称其次查询。
- `/OJ使用`：通过一条合并转发消息查看通用文字 OJ 登录教程。
- `/随机选手`：从当前榜单随机展示一人。
- `/提交记录 <昵称/学号/初始昵称>`：以合并转发查看该同学最近一页提交记录；昵称需完整匹配。
- `/帮助`：查看普通命令帮助。`/help` 保留给 AstrBot 内置命令。
- `/oj`：通用文字登录与使用教程。管理员通过 `oj_campus_url` 和 `oj_webvpn_url` 配置本校公开入口；不包含登录票据或凭据。
- `/pta`：通用文字注册、课程身份绑定与提交说明；实际课程及绑定信息由教师提供。
- `/周榜 [页码]`、`/月榜 [页码]`：查看本周、本月 OJ 排名图片。
- `/变化`、`/冲榜`、`/刷题榜`、`/提交榜`、`/新星榜`：查看今日数据榜单。

维护与统计命令（只有注明管理员权限的命令要求 OP）：

- `/开发者帮助`：查看维护与管理员命令说明。
- `/文字榜单`、`/榜单状态`、`/日榜`：文字备用与数据状态。
- `/统计数据 [全量]`、`/统计数据 班级 <班级>`、`/统计数据 专业 <专业>`：导出当前共享快照 CSV，仅 AstrBot 管理员（OP）可用。
- `/统计数据 #<快照编号>`：导出指定历史快照 CSV，仅 AstrBot 管理员（OP）可用。
- `/统计数据 本周`、`/统计数据 本月`：导出最近 7 天、30 天的周期变化 CSV；结束点取今日 00:00 附近的快照，**不包含今日数据**，仅 AstrBot 管理员（OP）可用。

群聊启用了静默守卫：仅允许本插件列出的 `/` 命令继续处理。普通群消息、@机器人、回复机器人消息以及未列入允许名单的命令静默丢弃；另兼容 /群分析、/群漫画、/增量状态；私聊不受该守卫影响。

首次联调时白名单默认为空，即所有会话可查询。确认可用后，请在 AstrBot 插件配置中填写 `allowed_users` 或 `allowed_groups`。

- `/更新日志`：查看插件内置更新说明。
